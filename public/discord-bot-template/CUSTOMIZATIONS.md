# Safe future changes

`index.js`, `package.json`, SQL files, and documentation are core project files. Keep them in the private GitHub repository.

`bot-config.json` is generated by the Portal portal. It contains selected media servers, exact command names, ticket categories, pricing and deployment metadata. Update the Discord Bot card, save it, download a fresh manifest, and commit the replacement.

`.env` is host-only. Never commit Discord tokens or provider API keys.

Preserve the protected configuration loader at the top of `index.js` when merging future code updates. Test ticket categories, selected provider commands, `/pricing`, and portal membership sync after every update.
